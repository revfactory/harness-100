# Venue Evaluation — Venue Evaluation Scorecard

Systematizes venue selection decision-making for the logistics-manager agent.

## Venue Evaluation Criteria (Weighted Scorecard)

| Criteria | Weight | Evaluation Items |
|----------|--------|-----------------|
| Accessibility | 20% | Public transport, parking, distance from airport |
| Capacity | 20% | Headcount, layout flexibility |
| Facilities and Equipment | 15% | AV, WiFi, power, lighting |
| Cost | 15% | Rental fee, ancillary costs, negotiation margin |
| Catering | 10% | In-house / external, quality, restrictions |
| Atmosphere | 10% | Design, brand fit |
| Service | 10% | Dedicated manager, responsiveness, experience |

## Venue Requirements by Event Type

| Event Type | Key Requirements | Layout | Watch Points |
|------------|-----------------|--------|-------------|
| Conference | Stage + screen + seating | Theater / Classroom | Audio, lighting |
| Workshop | Tables + whiteboards | Island / U-shape | Breakout spaces |
| Networking | Open space + bar | Cocktail | Flow, noise |
| Exhibition | Booth space + power | Grid / Open | Loading access, load capacity |
| Seminar | Podium + seating | Classroom | Q&A microphones |
| Gala Dinner | Round tables | Banquet | Stage, lighting |

## Site Visit Checklist

### Required Verification Items

- [ ] Capacity (maximum / recommended)
- [ ] Layout change availability
- [ ] AV equipment (projector, screen, microphone, speakers)
- [ ] WiFi (bandwidth, simultaneous connections)
- [ ] Power (outlet locations, capacity, distribution panel)
- [ ] Lighting (controllability, natural light)
- [ ] Acoustics (soundproofing, echo, external noise)
- [ ] Catering space (kitchen, service flow)
- [ ] Accessibility (elevator, disabled facilities)
- [ ] Parking (spaces, rates, valet)
- [ ] Loading / unloading (dock, elevator, time restrictions)
- [ ] Waiting areas (lobby, lounge)
- [ ] Restrooms (count, location, condition)
- [ ] Emergency exits / fire safety (safety standards, insurance)

### Mandatory Photo Items
1. Exterior / entrance
2. Main hall (empty)
3. AV equipment
4. Catering / kitchen
5. Restrooms / amenities
6. Parking / access route

## Contract Review Points

| Item | Key Points |
|------|-----------|
| Rental period | Whether setup / teardown time is included |
| Overage charges | Per-unit cost for time and headcount overages |
| Cancellation policy | Penalty by lead time (30 / 60 / 90 days) |
| Insurance | Venue insurance, event insurance |
| Catering restrictions | External vendor permission, corkage |
| Alcohol regulations | BYOB policy, license requirements |
| Decoration restrictions | Wall mounting, candles, flower petals |
| Noise restrictions | Decibel limits by time of day |
