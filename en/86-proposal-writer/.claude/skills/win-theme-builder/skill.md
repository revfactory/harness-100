# Win Theme Builder — Win Theme Development Framework

Strengthens the proposal differentiation strategy of the differentiator and client-analyst agents.

## Win Theme Definition

```
Win Theme = Client's core need + Our unique differentiating capability + Provable evidence

Formula:
"To help [client] solve [core challenge],
 we will apply [our differentiating capability]
 to deliver [quantifiable outcome]."
```

## Win Theme Development Process

### Step 1: Client Hot Button Analysis

| Analysis Item | Source | Analysis Focus |
|--------------|--------|---------------|
| Formal requirements | RFP/RFI | Stated evaluation criteria, weightings |
| Informal needs | Pre-sales meetings, industry trends | Real concerns, political context |
| Decision-making structure | Org chart, stakeholders | Final decision-maker's priorities |
| Fear of failure | Past failures | What they never want to repeat |

### Step 2: Competitive Positioning

| Category | Our Company | Competitor A | Competitor B |
|----------|------------|-------------|-------------|
| Strength 1 | ★★★ | ★★ | ★ |
| Strength 2 | ★★ | ★★★ | ★★ |
| Weakness 1 | ★ | ★★ | ★★★ |

**Ghost strategy** (indirectly highlighting competitor weaknesses):
- Never disparage competitors directly
- Emphasize indirectly: "The reason our X capability matters is..."
- Frame evaluation criteria so that your strengths are weighted appropriately

### Step 3: Win Theme Sentence Structure

#### Pattern by Theme Type

| Type | Pattern | Example |
|------|---------|---------|
| Results-based | "Proven across X similar projects..." | "Expertise proven across 47 financial-sector implementations" |
| Technology-based | "The only provider offering X..." | "The only platform supporting real-time analytics" |
| Team-based | "N experts with X years of experience..." | "3 dedicated PMs with an average of 15 years' experience" |
| Cost-based | "X% lower TCO than..." | "5-year TCO 30% lower than competing solutions" |
| Risk-based | "Eliminating risk through X..." | "Minimizing implementation risk through phased validation" |

## Win Theme Consistency Across the Proposal

### Theme Matrix

| Win Theme | Executive Summary | Solution | Pricing | References | Team |
|-----------|------------------|---------|---------|-----------|------|
| Theme 1: Expertise | ○ | ○ | | ○ | ○ |
| Theme 2: Cost efficiency | ○ | | ○ | ○ | |
| Theme 3: Risk management | ○ | ○ | | | ○ |

**Principle**: Every Win Theme must run through every major section of the proposal.

## Types of Differentiation Evidence

| Evidence Type | Persuasiveness | Example |
|--------------|---------------|---------|
| Quantitative results | ★★★★★ | "Client revenue increased by 23%" |
| Client testimonial | ★★★★ | "Letter of recommendation from CIO of XX Group" |
| Certification / award | ★★★★ | "AWS Advanced Partner" |
| Patent / IP | ★★★ | "Holder of 3 related patents" |
| Case study | ★★★ | "Detailed case study of a comparable project" |
| Team credentials | ★★ | "Team average tenure: 12 years" |

## Win Theme Insertion in Executive Summary

```markdown
## Executive Summary Structure

1. Empathy with client's situation (2–3 sentences)
   → "We deeply understand the [challenge] your organization faces."

2. Win Theme 1 statement (1 paragraph)
   → [Core capability] + [Evidence] + [Expected outcome]

3. Win Theme 2 statement (1 paragraph)
   → [Core capability] + [Evidence] + [Expected outcome]

4. Win Theme 3 statement (1 paragraph)
   → [Core capability] + [Evidence] + [Expected outcome]

5. Vision statement (2–3 sentences)
   → "When this proposal is realized, [future state]."
```

## Quality Checklist

| Item | Standard |
|------|---------|
| Number of themes | 2–4 (more than 4 dilutes focus) |
| Client connection | Each theme mapped to a client Hot Button |
| Differentiation | Content competitors cannot easily claim |
| Evidence | At least 1 quantitative proof point per theme |
| Consistency | Themes run through all major proposal sections |
| Ghost strategy | Competitor weaknesses indirectly highlighted |
